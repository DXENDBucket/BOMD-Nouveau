# BOMD & Nouveau

把 Bosses of Mass Destruction 的攻击能力编排为 Ars Nouveau 魔符。
当前是 **0.1.0-dev.5，Minecraft 1.21.1 / NeoForge** 的可测试实现。
Mod ID：`bomd_nouveau`。作者 EndXiom，许可 **LGPL v3**。

需要 Ars Nouveau、Ars Conflux 0.1.10 和 BOMD NeoForge 1.3.3，以及它们自己的前置。
Iron、Goety、Not Enough Glyphs、Hex Linker 均不是必需依赖。
公共源码保存在 `common/`；当前尚未制作 1.20.1 Forge 发行包。

## 首批魔符

| 魔符 | 类别 | 默认载荷耗蓝 | 行为 |
| --- | --- | ---: | --- |
| 巫妖飞弹 | 弹射物替换增强 | 40 | 默认 13.5 点基础伤害，保留原生缓慢 III / 5 秒 |
| 花瓣刃 | 弹射物替换增强 | 50 | 默认 18 点基础伤害 |
| 巫妖彗星 | 弹射物替换增强 | 300 | 原生威力 4 的爆炸 |
| 孢子球 | 弹射物替换增强 | 200 | 直接伤害、落地闪烁、1.5 秒后原生孢子喷发和中毒 |
| 彗星爆破 | 效果 | 300 | 在 Ars 触发位置执行同一份彗星爆炸 |
| 孢子喷发 | 效果 | 200 | 在 Ars 触发位置生成同一份延迟喷发 |
| 黑曜喷发 | 效果 | 200 | 触发位置半径 7 格的地面预警；1.5 秒后喷发、穿盾、击飞 |
| 熔火冲击波 | 效果 | 300 | 沿触发方向逐段喷发、击飞、点燃；保留原生推进节奏 |
| 黑曜突刺 | 效果 | 240 | 三轮追踪实体目标附近的地面，或重复攻击固定落点，附加缓慢 III |
| 地潜 | 效果 | 100 | 自身或选中的友军沿触发方向穿墙；自身触发按自身朝向，失败不扣蓝 |
| 巨拳激光 | 效果 | 150 / 持续秒 | 蓄力后发射 30 格红色光束，持续扫射并保留转向滞后；墙体截断，空蓝停止 |

全部为 Tier 1；不额外接入统一吟唱或冷却，巨拳激光保留自身的蓄力阶段。强化的载荷附加费每次为 10 Mana，
原版 Ars 形态、增强及后续效果的费用另算。创造模式免载荷费用。
巨拳激光有原生 25 tick（1.25 秒）蓄力，然后进入 60 tick 的持续阶段，瞄准使用原生 8 tick 历史。
默认每次有效受伤为 18，增强遵循伤害魔符配置；保留原版受伤无敌时间，不是每 tick 都扣 18 生命。
持续阶段每秒预付 150 Mana，最多三次；蓄力不扣费，但开始时需要足够支付第一秒。增强附加费也按持续秒计算。
自身／友军从眼部沿当前朝向发射；位置触发保留位置和入射方向。激光不会伤害发射者、施法者或其盟友。
光束原生贴图、绘制函数、蓄力声和红色粒子均来自 BOMD；不生成隐藏 Boss，不改变其原生攻击。
激光默认不破坏方块；后续 Ars 效果仍按原有触发位置执行，不会自动附着到每次激光伤害上。

示例：`弹射物 → 巫妖飞弹 → 增强 → 伤害`，或 `触摸 → 孢子喷发`。
替换载荷不会吞掉后续效果。同一形态段只能选择一种弹射物替换，这是 Conflux 的共用规则。
环绕等反复命中的载体按实际触发逐次付费，空蓝会停止当前载荷及其后续编排。

飞弹、花瓣刃及孢子伤害读取对应 Boss 的配置基础值 ×1.5，以困难模式对玩家
造成的护甲结算前伤害为固定基准，不读取施法者的近战属性。
每级增强增加 `EffectHarm.INSTANCE.AMP_VALUE`，原版默认是 2；修改 Ars「伤害」配置后一起改变。
彗星增强每级增加 0.5 爆炸威力，爆炸伤害仍由 Minecraft 计算。
默认关闭彗星破坏地形，可配置开启。

三个黑曜攻击魔符每次有效命中的基础伤害读取黑曜石柱的攻击配置 ×1.5，默认 24；增强按 Ars 伤害魔符的数值提升。
一次收费包含完整攻击序列，不会对冲击波的每个区间或突刺的每一轮再次收费。
实体目标的突刺采用速度预判，不依赖 Boss 专用的玩家历史位置记录，因此其他生物也可以被追踪。
地潜复用原生墙体搜索规则：附近约 3 格内找到墙，再向前寻找最多约 20 格的出口。
地潜属于增益行为，只作用于自身或原版盟友判定认可的生物（如同队生物）；未结盟的中立生物也不会被移动，拒绝目标不扣蓝。
不可破坏方块、未加载区域、世界边界或不足以容纳目标的落点会阻止传送；地潜不支持伤害增强。

在 Ars 抄写台消耗 **古老灵魂 / 虚空荆棘 ×1 + 魔源宝石 ×1 + 27 XP** 制作。
巫妖系列使用 `ancient_anima`，虚空之花系列使用 `void_thorn`。
三个黑曜攻击魔符使用 `obsidian_heart`，地潜使用 `earthdive_spear`；同样需要魔源宝石及 27 XP。
巨拳激光使用 `blazing_eye`、魔源宝石及 27 XP。
使用原生魔符学习方式、原生配方及 JEI 页面；图标引用对应 BOMD 材料。

## 配置

`bomd_nouveau-server.toml` 控制十一种魔符的载荷价格、增强附加费及彗星地形破坏。
它属于服务端配置；通常位于世界的 `serverconfig/`，测试环境也可能将其放在 `config/`。
不添加独立魔力池；使用 Conflux 的 Ars 账户和触发支付。

## 构建与许可

Java 21；相邻目录默认放置 Ars-Conflux 源码，也可用 `-PconfluxCheckout=...`。
将依赖放入本地 `libs/`，对应文件哈希见 `dependencies.lock.json`。
`./gradlew :jar :sourcesJar` 生成二进制和对应源码发行包。
`./gradlew :runGameTestServer` 运行本批服务端测试。

BOMD 作为单独依赖安装；本模组不打包其 JAR、贴图、模型或声音。
构建产物附带 LGPL、GPL、来源及修改声明，发行时同时提供对应源码。
